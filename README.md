# 🔢 Numeral System Odometer Converter

Интерактивное веб-приложение в стиле ретро-механического счетчика (одометра), которое в реальном времени синхронизирует и конвертирует значения между четырьмя популярными системами счисления.

🌐 **Посмотреть сайт вживую:** [GitHub Pages](https://AzizSohibov.github.io/Numeral-system-converter/)

---

## ✨ Особенности проекта

* **Механическая анимация цифр:** Плавный вертикальный сдвиг барабанов (`translateY` + кубические кривые Безье) имитирует работу классических механических счетчиков (например, счетчиков воды или автомобильных одометров).
* **Мгновенная синхронизация:** Поддержка четырех систем счисления одновременно:
  * **Hex** (16-ричная) — 4 разряда
  * **Decimal** (10-чная) — 6 разрядов
  * **Octal** (8-ричная) — 6 разрядов
  * **Binary** (Двоичная) — 12 разрядов
* **Интерактивные поля ввода:** Под каждым табло расположено поле ввода с валидацией в реальном времени. Изменение значения в любой системе моментально пересчитывает и обновляет все остальные счетчики.
* **Современный UI/UX:** Темная технологичная тема, стилизованные «окошки» с эффектом глубины и приятные hover-эффекты.

---

## 🛠️ Технологии

Проект написан на чистом стеке веб-технологий без использования сторонних библиотек и фреймворков:
* **HTML5** — семантическая разметка.
* **CSS3** (Flexbox, Grid, CSS Transitions, Custom Properties) — стилизация и плавная анимация.
* **JavaScript (ES6+)** — логика конвертации систем счисления, валидация ввода и управление DOM.
